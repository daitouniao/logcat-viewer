# logcore/filter Specification

## Purpose
定义 Rust core 的过滤契约：一份过滤条件模型、对装载完成文件源的全量扫描结论（升序文档行号结果集），以及正文匹配的作用域与大小写等价规则；宿主与 MCP 共用同一语义，UI 条件为其子集。本代只定义装载完成的文件源；采集源与其他生命周期状态不在范围。

## Requirements

### Requirement: 条件模型与组合

过滤条件 SHALL 由级别、进程号、线程号、时间戳分钟字段、tag 与正文子串六类组成。不同类别之间 MUST 全部满足。级别、进程号、线程号与分钟为集合条件，记录命中集合内任一值即满足；tag 与正文的多值组合可由调用方选择「全部命中」或「任一命中」，缺省 tag 为「任一命中」、正文为「全部命中」。tag 与正文缺省均按子串匹配。大小写与排除 SHALL 由调用方给出，默认忽略大小写、不排除；进程号、线程号、tag 与正文支持排除，级别与分钟不支持排除。任一类别取值为空集合时视为该类别未启用；正文条件即使因空词而恒真，MUST NOT 因此视为未启用。未提供任何类别（或该类别等同未启用）时结果集 MUST 为恒等视图。

#### Scenario: 无条件返回恒等视图

- **GIVEN** 文件源装载完成、文档有 1000 行
- **WHEN** 以不含任何条件的过滤表达式执行过滤
- **THEN** 结果集含全部 1000 行，顺序与文档一致

#### Scenario: 不同类别之间全部满足

- **GIVEN** 文档中一行级别为 Error、进程号为 100，另一行级别为 Error、进程号为 200
- **WHEN** 同时按级别 Error 与进程号 100 过滤
- **THEN** 只有第一行命中

#### Scenario: 同类多值任一命中

- **GIVEN** 文档含级别为 Debug、Info、Error 的各一行
- **WHEN** 以级别集合 Debug 与 Error 过滤
- **THEN** Debug 与 Error 两行命中，Info 不命中

### Requirement: 元数据条件与缺失元数据

启用级别条件时仅保留级别在集合内的记录；级别集合为空或恰为全部有效级别时视为未启用。启用进程号、线程号或分钟条件时，不具备该元数据的记录 MUST 不命中；进程号、线程号与 tag 在排除模式下 MUST 保留这些记录。tag 条件以记录 tag 文本判定，无 tag 的记录在启用时不命中、排除时保留。

#### Scenario: 全部级别等同未启用

- **GIVEN** 文档含全部有效级别各一行，另有一行级别未知
- **WHEN** 以「全部有效级别」作为级别条件过滤
- **THEN** 级别未知的行同样命中，结果与无条件一致

#### Scenario: 进程号排除

- **GIVEN** 文档含进程号 100、200 的行，以及一行进程号未知
- **WHEN** 以进程号 100、开启排除过滤
- **THEN** 进程号 100 的行被剔除，进程号 200 与进程号未知的行保留

#### Scenario: 线程号排除

- **GIVEN** 文档含线程号 200、300 的行，以及一行线程号未知
- **WHEN** 以线程号 200、开启排除过滤
- **THEN** 线程号 200 的行被剔除，线程号 300 与线程号未知的行保留

#### Scenario: 分钟条件与无时间戳记录

- **GIVEN** 文档一行时间戳分钟为 30，另一行无可识别时间戳
- **WHEN** 以分钟 30 过滤
- **THEN** 只有时间戳分钟为 30 的行命中

#### Scenario: 启用 tag 条件时无 tag 记录不命中

- **GIVEN** 文档含一行带 tag、一行不带 tag
- **WHEN** 以 tag 条件过滤且不开启排除
- **THEN** 不带 tag 的行不命中

### Requirement: tag 匹配方式与组合

tag 条件 SHALL 支持子串与整串两种匹配：子串匹配 MUST 判断 tag 文本是否包含给定值；整串匹配 MUST 判断 tag 文本是否与给定值相等；忽略大小写时，无论子串还是整串匹配，双方 MUST 先按 Unicode 小写化。「全部命中」与整串匹配组合时，单 tag 记录至多等于一个值，多个折叠后互不相同的值 MUST 视为无命中。排除模式下 MUST 保留未命中的记录。

#### Scenario: tag 子串匹配

- **GIVEN** 文档含 tag 为 `ActivityManager` 与 `WindowManager` 的行
- **WHEN** 以 tag `Manager`、子串匹配、任一命中过滤
- **THEN** 两行均命中

#### Scenario: tag 子串匹配全部命中

- **GIVEN** 文档含 tag 为 `ActivityManager` 的一行
- **WHEN** 以 tag `Activity` 与 `Manager`、子串匹配、全部命中过滤
- **THEN** 该行命中

#### Scenario: 子串匹配忽略大小写

- **GIVEN** 文档含 tag 为 `ActivityManager` 的一行
- **WHEN** 以 tag `manager`、子串匹配、忽略大小写过滤
- **THEN** 该行命中

#### Scenario: 整串匹配全部命中的多值

- **GIVEN** 文档含 tag 为 `Alpha` 的一行
- **WHEN** 以 tag `Alpha` 与 `Beta`、整串匹配、全部命中过滤
- **THEN** 该行不命中（单 tag 不能同时等于两个不同值）

#### Scenario: 整串匹配任一命中

- **GIVEN** 文档含 tag 为 `ActivityManager` 与 `WindowManager` 的行
- **WHEN** 以 tag `ActivityManager` 与 `WindowManager`、整串匹配、任一命中过滤
- **THEN** 两行均命中

#### Scenario: 整串匹配忽略大小写

- **GIVEN** 文档含 tag 为 `Alpha` 的一行
- **WHEN** 以 tag `alpha`、整串匹配、忽略大小写过滤
- **THEN** 该行命中

#### Scenario: 折叠后相同的多值在全部命中下成立

- **GIVEN** 文档含 tag 为 `Alpha` 的一行
- **WHEN** 以 tag `Alpha` 与 `alpha`、整串匹配、全部命中、忽略大小写过滤
- **THEN** 该行命中（两值折叠后相同）

#### Scenario: tag 排除

- **GIVEN** 文档含 tag 为 `ActivityManager` 与 `WindowManager` 的行
- **WHEN** 以 tag `ActivityManager`、开启排除过滤
- **THEN** `ActivityManager` 行被剔除，`WindowManager` 行保留

### Requirement: 正文匹配作用域

正文匹配 SHALL 只作用于记录正文：从日志头之后的消息起始位置到行尾，行尾为行终止符之前（`\n` 及紧邻其前的 `\r` 不计入）；行首时间戳、进程号、线程号、级别与 tag MUST NOT 参与正文匹配。消息起始位置以解析结果给出的消息偏移为准，该偏移之前为日志头；解析器未识别出消息起点的记录，整行视为正文。空正文 MUST 按长度为 0 的正文参与匹配：条件值为空词时命中，非空时不命中。正文取装载时的文件内容，与分页读取同源。

#### Scenario: 头部信息不参与匹配

- **GIVEN** 一行 tag 为 `ActivityManager`、正文不含该词
- **WHEN** 以 `ActivityManager` 作为正文条件过滤
- **THEN** 该行不命中

#### Scenario: 正文命中

- **GIVEN** 一行正文含 `started`
- **WHEN** 以 `started` 作为正文条件过滤
- **THEN** 该行命中

#### Scenario: 续行按自身正文参与匹配

- **GIVEN** 一行缩进续行正文含 `Foo.bar`，其上方记录的正文不含该词
- **WHEN** 以 `Foo.bar` 作为正文条件过滤
- **THEN** 命中的是续行自身，上方记录不命中

#### Scenario: 空正文与空词

- **GIVEN** 一行正文为空
- **WHEN** 以空词作为正文条件过滤
- **THEN** 该行命中

#### Scenario: 空正文与非空词

- **GIVEN** 一行正文为空
- **WHEN** 以 `started` 作为正文条件过滤
- **THEN** 该行不命中

### Requirement: 正文大小写等价

本子串模式下忽略大小写（默认）时，比较双方 SHALL 按 Unicode 小写化后逐字节相等即命中：ASCII 字母大小写 MUST 等价，`ß` 与 `ẞ` MUST 等价，带重音与不带重音 MUST NOT 等价，土耳其无点 `ı` 与 ASCII `i` MUST NOT 等价。区分大小写时 MUST 按原始字节精确比较。无法按 UTF-8 解码的正文 MUST 按替换字符参与小写化，MUST NOT 影响同一文档其余记录的判定。正则模式的大小写等价另按正则档判定，MUST NOT 套用本条的折叠口径。

#### Scenario: ASCII 大小写双向等价

- **GIVEN** 一行正文含 `Plain ASCII`
- **WHEN** 分别以 `plain`、`PLAIN`、`PlAiN` 过滤
- **THEN** 三次结果一致，该行均命中

#### Scenario: 区分大小写严格比较

- **GIVEN** 一行正文含 `PLAIN`
- **WHEN** 以 `plain` 过滤且开启区分大小写
- **THEN** 该行不命中

#### Scenario: 德语 eszett 等价

- **GIVEN** 一行正文含 `Straße`，另一行含 `ẞ`
- **WHEN** 以 `ß` 过滤且忽略大小写
- **THEN** 两行均命中

#### Scenario: 开尔文符号折叠为 ASCII k

- **GIVEN** 一行正文含 ASCII `k`
- **WHEN** 以开尔文符号（U+212A）过滤且忽略大小写
- **THEN** 该行命中

#### Scenario: 土耳其无点 i 不等价

- **GIVEN** 一行正文只含 `ı`，不含 ASCII 的 i 或 I
- **WHEN** 以 `i` 过滤且忽略大小写
- **THEN** 该行不命中

#### Scenario: 重音字符不等价

- **GIVEN** 一行正文含 `CAFÉ`，另一行含 `cafe`
- **WHEN** 以 `café` 过滤且忽略大小写
- **THEN** 只有含 `CAFÉ` 的行命中

#### Scenario: 非法 UTF-8 按替换字符参与比较

- **GIVEN** 一行正文含无法按 UTF-8 解码的字节，其余行正文正常
- **WHEN** 以含替换字符的正文条件、忽略大小写过滤
- **THEN** 含非法字节的行按替换字符命中，其余行的判定不受影响

### Requirement: 正文多值与排除

正文条件 SHALL 支持「全部命中」与「任一命中」，可由调用方选择，缺省为全部命中。空词在「任一命中」下 MUST 立即成立，在「全部命中」下 MUST 跳过、不构成否决。排除模式下 MUST 保留未命中的记录。子串模式下条件值为非空词时，空正文视为未命中并在排除模式下保留；条件值为空词时，空正文按空词语义命中，排除模式下按命中剔除。正则模式下空正文按空文本参与求值，不受本子串模式空正文条款约束。

#### Scenario: 任一命中

- **GIVEN** 文档一行正文含 `start`，一行含 `timeout`
- **WHEN** 以 `start` 与 `timeout`、任一命中过滤
- **THEN** 两行均命中

#### Scenario: 全部命中

- **GIVEN** 一行正文同时含 `start` 与 `failed`
- **WHEN** 以 `start` 与 `failed`、全部命中过滤
- **THEN** 该行命中

#### Scenario: 空词在任一命中下立即成立

- **GIVEN** 条件含空词与一个不存在的词，组合方式为任一命中
- **WHEN** 执行过滤
- **THEN** 全部记录命中

#### Scenario: 空词在全部命中下不否决

- **GIVEN** 条件含空词与一个存在的词，组合方式为全部命中
- **WHEN** 执行过滤
- **THEN** 结果与只用该存在的词过滤相同

#### Scenario: 全部为空词的全部命中模式

- **GIVEN** 正文条件只含空词，组合方式为全部命中
- **WHEN** 执行过滤
- **THEN** 全部记录命中

#### Scenario: 空词在任一命中下与排除

- **GIVEN** 文档含正文非空的行，条件含空词与一个不存在的词，组合方式为任一命中，开启排除
- **WHEN** 执行过滤
- **THEN** 结果为空

#### Scenario: 全部为空词的全部命中与排除

- **GIVEN** 文档含任意记录，正文条件只含空词，组合方式为全部命中，开启排除
- **WHEN** 执行过滤
- **THEN** 结果为空

#### Scenario: 排除模式保留未命中记录

- **GIVEN** 文档一行正文含 `start`，一行不含，一行正文为空
- **WHEN** 以 `start`、开启排除过滤
- **THEN** 含 `start` 的行被剔除，其余两行保留

### Requirement: 结果集形态与顺序

有命中时结果集 SHALL 为严格升序、不重复的文档行号序列，且只含文档记录行（空行与横幅行从不入集）；无命中或空文档时为空结果集。结果集序号与文档行号分离，同一文档行号在结果集中至多出现一次。结果集内容 MUST NOT 因内部扫描方式不同而改变。

#### Scenario: 结果集升序不重复

- **GIVEN** 文档中第 3、7、8 行命中同一条件
- **WHEN** 执行过滤
- **THEN** 结果集依次为 3、7、8，不含重复项

#### Scenario: 空行与横幅不入结果集

- **GIVEN** 文档含空行、横幅行与若干记录行
- **WHEN** 执行过滤
- **THEN** 结果集只含记录行的文档行号

#### Scenario: 无命中返回空结果集

- **GIVEN** 文档中没有任何行命中条件
- **WHEN** 执行过滤
- **THEN** 结果集为空，不报错

#### Scenario: 块长不影响结论

- **GIVEN** 同一份文档与同一份条件，正文命中横跨块边界且候选稀疏
- **WHEN** 分别以默认块长与极小测试块长执行过滤
- **THEN** 两者结果集完全相同

### Requirement: 导航定位

结果集 MUST 支持按真实文档行号定位最近的结果行：该行在结果集中即返回对应位置；不在结果集中时取前后相邻结果行中距离更近者，距离相等取前一条；小于首条结果行取首条，大于末条结果行取末条；空结果集无定位。定位 MUST NOT 改变结果集。

#### Scenario: 命中定位

- **GIVEN** 结果集为文档行 3、7、8
- **WHEN** 按文档行 7 定位
- **THEN** 返回对应第 7 行的结果位置

#### Scenario: 平局取前一条

- **GIVEN** 结果集为文档行 0、2、5
- **WHEN** 按文档行 1 定位（到 0 与 2 距离相等）
- **THEN** 返回文档行 0 对应的结果位置

#### Scenario: 越界取首末

- **GIVEN** 结果集为文档行 2、5
- **WHEN** 分别按文档行 0 与文档行 9 定位
- **THEN** 前者返回首条，后者返回末条

#### Scenario: 空结果集无定位

- **GIVEN** 结果集为空
- **WHEN** 按任意文档行定位
- **THEN** 返回无定位，不报错

### Requirement: 与分页协作

过滤结果交给分页时，起点 SHALL 为真实文档行号而非结果集序号，并区分「锚点定位」与「顺序翻页」两种意图。锚点定位用于过滤条件变化后恢复视图：起点为宿主当前锚点，入口 MUST 定位结果集中最近的结果行——命中即自身；未命中取前后相邻结果行中距离更近者，距离相等取前一条；小于首条取首条，大于末条取末条；结果集为空时返回空页，不报错。顺序翻页用于连续加载：宿主传上一页末行的文档行号加一，入口 MUST 只向后定位第一条文档行号不小于起点的结果行，没有这样的结果行时 SHALL 返回空页，MUST NOT 向前回退。两种意图 MUST NOT 互相替代。过滤 MUST NOT 改变分页的条数上限、空页与错误口径。

#### Scenario: 按真实文档行起页

- **GIVEN** 结果集为文档行 2、5、9
- **WHEN** 以文档行 5 为起点请求一页
- **THEN** 页首为文档行 5 的命中行，不把 5 当结果集序号

#### Scenario: 顺序翻页不重复

- **GIVEN** 一页末行为文档行 5
- **WHEN** 以文档行 6 为起点请求下一页
- **THEN** 下一页从文档行 9 的命中行开始，不重复文档行 5

#### Scenario: 锚点被过滤掉取最近结果

- **GIVEN** 结果集为文档行 2、5、9，宿主当前锚点为文档行 7（不在结果集中）
- **WHEN** 以锚点定位请求一页
- **THEN** 页首为文档行 5 的命中行（到 5 与 9 距离相等，取前一条）

#### Scenario: 锚点超过末条结果取末条

- **GIVEN** 结果集为文档行 2、5、9，宿主当前锚点为文档行 10
- **WHEN** 以锚点定位请求一页
- **THEN** 页首为文档行 9 的命中行，不返回空页

#### Scenario: 空结果集锚点定位返回空页

- **GIVEN** 结果集为空
- **WHEN** 以任意文档行作为锚点请求一页
- **THEN** 返回空页，不报错

#### Scenario: 顺序翻页超过末条返回空页

- **GIVEN** 结果集为文档行 2、5、9，上一页末行为文档行 9
- **WHEN** 以文档行 10 为起点顺序翻页
- **THEN** 返回空页，不向前回退到文档行 9

### Requirement: 读取错误与装载内容一致

正文回读失败（源文件被截断、不可读或区间不足）时 MUST 返回读取错误并携带源路径与系统错误信息，MUST NOT 产出部分结果集，MUST NOT 改变源句柄状态。源文件在装载后被改名轮转、删除或替换时，过滤 MUST 继续以装载时的文件内容判定，不混入新内容。

#### Scenario: 源文件被截断

- **GIVEN** 文档装载完成后源文件被外部截断
- **WHEN** 执行需要回读正文的过滤
- **THEN** 返回读取错误并携带源路径与系统错误信息，不产出部分结果集，句柄状态不变

#### Scenario: 轮转后仍按装载内容判定

- **GIVEN** 文档装载完成后源文件被改名轮转
- **WHEN** 执行需要正文回读的过滤
- **THEN** 命中结论与装载时内容一致，不混入轮转后的新文件

#### Scenario: 替换后仍按装载内容判定

- **GIVEN** 文档装载完成后原路径被另一份文件替换
- **WHEN** 执行需要正文回读的过滤
- **THEN** 命中结论仍基于装载时的文件内容

#### Scenario: 删除后仍按装载内容判定

- **GIVEN** 文档装载完成后源文件被删除
- **WHEN** 执行需要回读正文的过滤
- **THEN** 命中结论与装载时内容一致

### Requirement: 过滤为只读操作

过滤 MUST NOT 修改索引快照、缓存、事件与进度，MUST NOT 使既有结果集或分页读取失效。同一份文档与同一份条件重复执行 MUST 得到相同结果集。

#### Scenario: 重复执行结果一致

- **GIVEN** 文件源装载完成
- **WHEN** 以同一条件连续执行两次过滤
- **THEN** 两次结果集完全相同

#### Scenario: 不改动既有读取

- **GIVEN** 文件源装载完成并已读取过一页
- **WHEN** 执行一次过滤
- **THEN** 既有分页读取的内容与行为不变

### Requirement: 正则模式参与正文过滤

正文条件 SHALL 支持两种匹配方式：子串（缺省）与正则。正则模式 MUST 只作用于记录正文，其作用域、全部/任一组合、排除语义与结果集形态 MUST 与子串模式共用同一契约。正则档 SHALL 只回答「该行正文是否被 pattern 集合按组合方式命中」，MUST NOT 给出命中位置或抽取子串。

#### Scenario: 同一条件重复开启结果一致

- **GIVEN** 文件源装载完成
- **WHEN** 以同一组正文正则连续开启两次查询
- **THEN** 两次命中的行集完全相同

#### Scenario: 通配跨度只命中目标行

- **GIVEN** 一行正文含 `ANR in com.example.process`，另一行正文含 `ANR in` 后不带包名
- **WHEN** 以正则 `ANR in com\..*` 过滤
- **THEN** 只有第一行命中

#### Scenario: 正则档头部信息不参与匹配

- **GIVEN** 一行 tag 为 `ActivityManager`，其正文不含该词
- **WHEN** 以正则 `[Aa]ctivity\w*` 作为正文条件过滤
- **THEN** 该行不命中

#### Scenario: 只判存在性不回传命中位置

- **GIVEN** 一行正文同时命中两条 pattern
- **WHEN** 以正则档过滤
- **THEN** 结果集只含该行的文档行号，不携带命中位置或命中词

#### Scenario: 正则档排除剔除命中行

- **GIVEN** 文档三行正文，其中一行命中给定正则
- **WHEN** 以该正则、开启排除过滤
- **THEN** 命中的行被剔除，其余两行保留

#### Scenario: 正则档全部命中

- **GIVEN** 一行正文同时含 `GC` 与 `pause`，另一行只含 `GC`
- **WHEN** 以两条正则、全部命中过滤
- **THEN** 只有同时含两者的行命中

### Requirement: 正则档的正文归一化

正则档 SHALL 与子串档同源取正文，并 MUST 在求值前把无法按 UTF-8 解码的字节归一为替换字符；含非法字节的行 MUST 与合法行同等参与求值，MUST NOT 影响同一文档其余记录的判定。同一行的归一化结论 MUST 被该行全部 pattern 复用，判定结果 MUST NOT 随 pattern 条数或提交顺序而变。

#### Scenario: 非法字节按替换字符命中

- **GIVEN** 一行正文含无法按 UTF-8 解码的字节，界面上显示为替换字符
- **WHEN** 以匹配替换字符的正则过滤
- **THEN** 该行命中

#### Scenario: 非法字节两侧可被通配跨连

- **GIVEN** 同一行正文中非法字节前后各有一个可见字符
- **WHEN** 以把这两个字符直接相邻书写的正则（中间无元字符）过滤
- **THEN** 该行命中（非法字节占一个可匹配位置）

#### Scenario: 条数与顺序不改变判定

- **GIVEN** 同一份文档，正文条件为若干条正则
- **WHEN** 分别以该条件与其逆序提交过滤
- **THEN** 两次结果集完全相同

### Requirement: 正则档的空正文与空 pattern

正则模式下空正文行 SHALL 按长度为 0 的文本参与求值：能匹配空串的 pattern 在其上命中，不能匹配空串的 pattern 不命中。空 pattern SHALL 视为可在任意位置匹配，其全部命中/任一命中与排除的结论 MUST 与子串档的空词语义一致。正文条件为空集合时仍视为该类别未启用，空字符串取值 MUST NOT 被归一为未启用。

#### Scenario: 锚点正则命中空正文

- **GIVEN** 文档含一行正文为空、若干行正文非空
- **WHEN** 以只能匹配空串的首尾锚点正则过滤
- **THEN** 只有正文为空的行命中

#### Scenario: 通配正则命中空正文

- **GIVEN** 一行正文为空
- **WHEN** 以匹配任意长度（含零长）的正则过滤
- **THEN** 该行命中

#### Scenario: 单词边界正则不命中空正文

- **GIVEN** 一行正文为空
- **WHEN** 以只含单词边界的正则过滤
- **THEN** 该行不命中

#### Scenario: 空 pattern 与排除

- **GIVEN** 文档含任意若干记录
- **WHEN** 以只含空字符串取值的正则条件、开启排除过滤
- **THEN** 结果为空（空 pattern 恒命中，排除后全部剔除）

#### Scenario: 空集合取值仍为未启用

- **GIVEN** 文件源装载完成
- **WHEN** 提交正文条件为空集合、其他条件为空的过滤
- **THEN** 结果集为恒等视图

### Requirement: 正则档大小写等价

正则模式下 `case` 缺省（忽略大小写）时 SHALL 按 Unicode 大小写折叠求值：ASCII 字母大小写 MUST 等价，`ß` 与 `ẞ` MUST 等价，带重音与不带重音 MUST NOT 等价。`case` 为区分大小写时 MUST 按码点精确求值，但 pattern 内自行声明的大小写开关 SHALL 仍按正则方言生效。

#### Scenario: 缺省忽略大小写

- **GIVEN** 一行正文含 `TIMEOUT`
- **WHEN** 以正则 `timeout` 过滤且未区分大小写
- **THEN** 该行命中

#### Scenario: 区分大小写后不命中

- **GIVEN** 一行正文含 `TIMEOUT`
- **WHEN** 以正则 `timeout` 过滤且开启区分大小写
- **THEN** 该行不命中

#### Scenario: pattern 内大小写开关仍生效

- **GIVEN** 一行正文含 `Timeout`
- **WHEN** 以在 pattern 内自行声明忽略大小写的 `timeout` 过滤且开启区分大小写
- **THEN** 该行命中（pattern 内开关不被外层区分大小写抹掉）

#### Scenario: pattern 内关闭忽略大小写仍生效

- **GIVEN** 一行正文含 `timeout`，另一行含 `TIMEOUT`
- **WHEN** 以在 pattern 内自行声明区分大小写的 `timeout` 过滤且未开启区分大小写
- **THEN** 仅正文为 `timeout` 的那行命中（pattern 内开关不被外层缺省抹掉，与上一条互为反向）

#### Scenario: 折叠后的德语大写 eszett 等价

- **GIVEN** 一行正文含 `straße`，另一行含 `STRAẞE`
- **WHEN** 以正则 `strasse` 过滤且未区分大小写
- **THEN** 两行均不命中；改以 `ß` 书写时两行均命中

### Requirement: 正则方言边界

正文正则 SHALL 采用线性时间求值的方言，MUST NOT 支持环视（前视与后视）、反向引用与原子组；提交这些写法 MUST 按语法不合法拒绝，MUST NOT 静默忽略或降级。该方言不含独占量词，`x*+` 一类写法 SHALL 按量词叠加接受，MUST NOT 按语法不合法拒绝。`\w` `\d` `\s` `\b` MUST 按 Unicode 语义求值，字符类集合运算与 Unicode 属性类 SHALL 可用。pattern 内的内联写法（大小写、宽松、回车换行、Unicode 开关）SHALL 按该方言生效，MUST NOT 被外层条件字段抹掉。pattern 的合法与否 MUST 只由 core 判定，宿主 MUST NOT 以其他引擎的语法结论替代。

#### Scenario: 前视被拒

- **GIVEN** 文件源装载完成
- **WHEN** 提交含前瞻环视的正文正则
- **THEN** 开启查询时按正则无效拒绝并标明原因是语法，不产出结果集

#### Scenario: 反向引用被拒

- **GIVEN** 文件源装载完成
- **WHEN** 提交含序号反向引用的正文正则
- **THEN** 按正则无效拒绝并标明原因是语法

#### Scenario: 原子组被拒

- **GIVEN** 文件源装载完成
- **WHEN** 提交以原子组包裹正文的正文正则
- **THEN** 按正则无效拒绝并标明原因是语法

#### Scenario: 量词叠加写法按叠加求值

- **GIVEN** 文件源装载完成
- **WHEN** 提交形如 `x*+` 的正文正则
- **THEN** 正常接受并按量词叠加求值，不报语法不合法（该方言无独占量词，与其他引擎的结论不同）

#### Scenario: Unicode 词类命中中文正文

- **GIVEN** 一行正文为中文词语
- **WHEN** 以「一个或多个词字符」的正则过滤
- **THEN** 该行命中（词字符不限于 ASCII）

#### Scenario: 属性类可用

- **GIVEN** 一行正文含大写字母
- **WHEN** 以按 Unicode 字母类别书写的正则过滤
- **THEN** 该行命中

#### Scenario: 宽松写法忽略模式内空白

- **GIVEN** 一行正文含连写的 `ab`，另一行正文含带空白的 `a b`
- **WHEN** 两行分别以开启宽松模式、模式内写作 `a b` 的正则过滤
- **THEN** 仅连写那行命中（为对齐而写的空白不被当作要匹配的字符）；把模式内的空白改为转义空白后，带空白那行命中

#### Scenario: 关闭 Unicode 语义后词类只认 ASCII

- **GIVEN** 一行正文为中文词语，另一行正文为 ASCII 单词
- **WHEN** 分别以默认写法与关闭 Unicode 语义的写法提交「一个或多个词字符」的正则过滤
- **THEN** 默认写法两行均命中；关闭后仅 ASCII 那行命中（该写法合法，语义按正则方言生效）

#### Scenario: 回车换行模式下的行尾锚点

- **GIVEN** 一行正文为「回车 + 换行 + `foo` + 回车 + 换行」
- **WHEN** 分别以「仅开启多行」与「同时开启多行与回车换行」两种写法的 `^foo$` 过滤
- **THEN** 前者不命中（`\r` 不被当作行尾分隔），后者命中（回车换行整体视为一处行边界）

### Requirement: 字面量型正则与子串档同结论

区分大小写时，把所有元字符均已转义（等价于纯文本）的 pattern 以正则模式提交，其命中行集 MUST 与把同一文本以子串模式提交的结果集完全相同。忽略大小写时二者 MAY 不同，差异 MUST NOT 出现在纯 ASCII 正文上。

#### Scenario: 转义点号与子串同集

- **GIVEN** 一份文档，部分行含字面 `tim.eout`，部分行含 `timxeout`
- **WHEN** 分别以区分大小写的子串条件 `tim.eout` 与正则条件 `tim\.eout` 过滤
- **THEN** 两次结果集相同，均只含字面 `tim.eout` 的行

#### Scenario: 未转义点号不是字面量

- **GIVEN** 同一份文档
- **WHEN** 以区分大小写的正则 `tim.eout` 过滤
- **THEN** `timxeout` 的行也命中，与子串档结论不同（该 pattern 含元字符，不受上一条约束）

### Requirement: 正则条件的规模上限

单条正文正则的字符数 MUST 有上限（2000 字符），同一正文条件的正则条数 MUST 有上限（16 条），且实现 MUST 另设编译规模上限以拒绝长度合规但展开规模失控的 pattern。三者取值 SHALL 在实现口径中固定，不因源文件内容与调用方而变。

#### Scenario: 单条超长被拒

- **GIVEN** 文件源装载完成
- **WHEN** 提交字符数超过上限的正文正则
- **THEN** 按正则无效拒绝并标明原因是长度超限

#### Scenario: 条数超限被拒

- **GIVEN** 文件源装载完成
- **WHEN** 同一正文条件提交超过条数上限的正则
- **THEN** 按正则无效拒绝并标明原因是条数超限

#### Scenario: 规模失控被拒

- **GIVEN** 文件源装载完成
- **WHEN** 提交长度合规、但展开后编译规模超过实现上限的正则
- **THEN** 按正则无效拒绝并标明原因是规模超限

#### Scenario: 常见写法不受上限影响

- **GIVEN** 文件源装载完成
- **WHEN** 分别提交含 20 个分支的合并正则、2000 字符纯字面量与逐字符量词串联的正文正则
- **THEN** 三者均被接受，不触发规模类拒绝

### Requirement: 非法正则条件被拒绝

正文正则不合法规则（语法不合法、长度超限、条数超限、编译规模超限）时 MUST 在开启查询时同步拒绝，MUST NOT 静默降级为子串匹配、MUST NOT 产出部分结果集、MUST NOT 改变源句柄状态。拒绝 SHALL 使用专用错误码「正则无效（17）」而非参数错误，参数 MUST 只携带语义键：必带原因（语法 / 长度超限 / 条数超限 / 规模超限），能归因到具体某条时附带其序号，MUST NOT 携带文案。

#### Scenario: 语法错误同步返回

- **GIVEN** 文件源装载完成
- **WHEN** 以含未闭合分组的正文正则开启查询
- **THEN** 同步返回正则无效、原因为语法，不产出结果集，句柄仍可正常用于后续查询

#### Scenario: 原因区分语法与规模

- **GIVEN** 文件源装载完成
- **WHEN** 分别以未闭合分组与合规但规模失控的 pattern 开启查询
- **THEN** 两次返回同一错误码，参数中的原因互不相同

#### Scenario: 归因能定位到单条时才附带序号

- **GIVEN** 文件源装载完成
- **WHEN** 以其中第二条语法非法、其余各条合规的多条正文正则开启查询
- **THEN** 参数中的序号指向第二条；改由整组编译规模超限触发拒绝时不附带序号，因为该拒绝无法归因到单条

#### Scenario: 不降级为子串

- **GIVEN** 一行正文含字面 `(abc`
- **WHEN** 以语法不合法的正则 `(abc` 开启查询
- **THEN** 返回正则无效，不返回按子串匹配该文本的结果集

### Requirement: 参数类无效条件被拒绝

未知的匹配方式或组合方式、级别不在 1–7、分钟不在 0–59、为负的进程号或线程号、tag 条件中的空字符串取值 MUST 被拒绝为参数错误，并在参数中标明无效项。类型不符或 JSON 形状非法的条件 MUST 被拒绝为参数错误，并标明整个过滤表达式无效；其他无法归因到具体类别的错误同样标明整个过滤表达式无效。被拒绝的过滤 MUST NOT 产出结果集。正文匹配的取值方式仅接受子串与正则两种，其他取值 MUST 被拒绝为参数错误并标明无效项；正则模式自身的不合法内容不属于本条，按正则档的专用拒绝处理。本代未支持的类别或字段（如时间区间、标记）MUST 被拒绝为参数错误，并标明整个过滤表达式无效，MUST NOT 静默忽略。

#### Scenario: 未知组合方式被拒

- **GIVEN** 文件源装载完成
- **WHEN** 以「介于全部命中与任一命中之间」的未知组合方式提交过滤
- **THEN** 返回参数错误并指明无效的是组合方式，不产出结果集

#### Scenario: 分钟超出范围被拒

- **GIVEN** 文件源装载完成
- **WHEN** 以 60 作为分钟取值提交过滤
- **THEN** 返回参数错误并指明无效的是分钟条件，不产出结果集

#### Scenario: 未知正文匹配方式被拒

- **GIVEN** 文件源装载完成
- **WHEN** 以既非子串也非正则的正文匹配方式提交过滤
- **THEN** 返回参数错误并指明无效的是正文匹配方式，不产出结果集

#### Scenario: 级别取值越界被拒

- **GIVEN** 文件源装载完成
- **WHEN** 以 0 或 8 作为级别取值提交过滤
- **THEN** 返回参数错误并指明无效的是级别条件，不产出结果集

#### Scenario: 负进程号被拒

- **GIVEN** 文件源装载完成
- **WHEN** 以 -1 作为进程号提交过滤
- **THEN** 返回参数错误并指明无效的是进程号条件，不产出结果集

#### Scenario: 空 tag 值被拒

- **GIVEN** 文件源装载完成
- **WHEN** 以空串作为 tag 值提交过滤
- **THEN** 返回参数错误并指明无效的是 tag 条件，不产出结果集

#### Scenario: 未支持类别被拒

- **GIVEN** 文件源装载完成
- **WHEN** 提交含标记条件的过滤
- **THEN** 返回参数错误并标明整个过滤表达式无效，不产出结果集

#### Scenario: 类型不符被拒

- **GIVEN** 文件源装载完成
- **WHEN** 以字符串作为级别取值提交过滤
- **THEN** 返回参数错误并标明整个过滤表达式无效，不产出结果集
