# logcore/filter Specification

## Purpose
定义 Rust core 的过滤契约：一份过滤条件模型、对装载完成文件源的全量扫描结论（升序文档行号结果集），以及正文匹配的作用域与大小写等价规则；宿主与 MCP 共用同一语义，UI 条件为其子集。本代只定义装载完成的文件源；采集源与其他生命周期状态不在范围。

## Requirements

### Requirement: 条件模型与组合

过滤条件 SHALL 由级别、进程号、线程号、时间戳分钟字段、tag 与正文子串六类组成。不同类别之间 MUST 全部满足。级别、进程号、线程号与分钟为集合条件，记录命中集合内任一值即满足；tag 与正文的多值组合可由调用方选择「全部命中」或「任一命中」，缺省 tag 为「任一命中」、正文为「全部命中」。tag 与正文缺省均按子串匹配。大小写与排除 SHALL 由调用方给出，默认忽略大小写、不排除；进程号、线程号、tag 与正文支持排除，级别与分钟不支持排除。任一类别取值为空集合时视为该类别未启用；正文条件即使因空词而恒真，MUST NOT 因此视为未启用。未提供任何类别（或该类别等同未启用）时结果集 MUST 为恒等视图。

#### Scenario: 无条件返回恒等视图

- **GIVEN** 文件源装载完成、文档有 1000 行
- **WHEN** 以不含任何条件的过滤表达式执行过滤
- **THEN** 结果集含全部 1000 行，顺序与文档一致

#### Scenario: 不同类别之间全部满足

- **GIVEN** 文档中一行级别为 Error、进程号为 100，另一行级别为 Error、进程号为 200
- **WHEN** 同时按级别 Error 与进程号 100 过滤
- **THEN** 只有第一行命中

#### Scenario: 同类多值任一命中

- **GIVEN** 文档含级别为 Debug、Info、Error 的各一行
- **WHEN** 以级别集合 Debug 与 Error 过滤
- **THEN** Debug 与 Error 两行命中，Info 不命中

### Requirement: 无效条件被拒绝

未知的匹配方式或组合方式、级别不在 1–7、分钟不在 0–59、为负的进程号或线程号、tag 条件中的空字符串取值 MUST 被拒绝为参数错误，并在参数中标明无效项。类型不符或 JSON 形状非法的条件 MUST 被拒绝为参数错误，并标明整个过滤表达式无效；其他无法归因到具体类别的错误同样标明整个过滤表达式无效。被拒绝的过滤 MUST NOT 产出结果集。本代正文仅支持子串匹配，以正则模式提交 MUST 被拒绝，不做静默降级。本代未支持的类别或字段（如时间区间、标记）MUST 被拒绝为参数错误，并标明整个过滤表达式无效，MUST NOT 静默忽略。

#### Scenario: 未知组合方式被拒

- **GIVEN** 文件源装载完成
- **WHEN** 以「介于全部命中与任一命中之间」的未知组合方式提交过滤
- **THEN** 返回参数错误并指明无效的是组合方式，不产出结果集

#### Scenario: 分钟超出范围被拒

- **GIVEN** 文件源装载完成
- **WHEN** 以 60 作为分钟取值提交过滤
- **THEN** 返回参数错误并指明无效的是分钟条件，不产出结果集

#### Scenario: 正则模式被拒

- **GIVEN** 文件源装载完成
- **WHEN** 以正则模式提交正文条件
- **THEN** 返回参数错误并指明正文匹配方式不受支持，不产出结果集

#### Scenario: 级别取值越界被拒

- **GIVEN** 文件源装载完成
- **WHEN** 以 0 或 8 作为级别取值提交过滤
- **THEN** 返回参数错误并指明无效的是级别条件，不产出结果集

#### Scenario: 负进程号被拒

- **GIVEN** 文件源装载完成
- **WHEN** 以 -1 作为进程号提交过滤
- **THEN** 返回参数错误并指明无效的是进程号条件，不产出结果集

#### Scenario: 空 tag 值被拒

- **GIVEN** 文件源装载完成
- **WHEN** 以空串作为 tag 值提交过滤
- **THEN** 返回参数错误并指明无效的是 tag 条件，不产出结果集

#### Scenario: 未支持类别被拒

- **GIVEN** 文件源装载完成
- **WHEN** 提交含标记条件的过滤
- **THEN** 返回参数错误并标明整个过滤表达式无效，不产出结果集

#### Scenario: 类型不符被拒

- **GIVEN** 文件源装载完成
- **WHEN** 以字符串作为级别取值提交过滤
- **THEN** 返回参数错误并标明整个过滤表达式无效，不产出结果集

### Requirement: 元数据条件与缺失元数据

启用级别条件时仅保留级别在集合内的记录；级别集合为空或恰为全部有效级别时视为未启用。启用进程号、线程号或分钟条件时，不具备该元数据的记录 MUST 不命中；进程号、线程号与 tag 在排除模式下 MUST 保留这些记录。tag 条件以记录 tag 文本判定，无 tag 的记录在启用时不命中、排除时保留。

#### Scenario: 全部级别等同未启用

- **GIVEN** 文档含全部有效级别各一行，另有一行级别未知
- **WHEN** 以「全部有效级别」作为级别条件过滤
- **THEN** 级别未知的行同样命中，结果与无条件一致

#### Scenario: 进程号排除

- **GIVEN** 文档含进程号 100、200 的行，以及一行进程号未知
- **WHEN** 以进程号 100、开启排除过滤
- **THEN** 进程号 100 的行被剔除，进程号 200 与进程号未知的行保留

#### Scenario: 线程号排除

- **GIVEN** 文档含线程号 200、300 的行，以及一行线程号未知
- **WHEN** 以线程号 200、开启排除过滤
- **THEN** 线程号 200 的行被剔除，线程号 300 与线程号未知的行保留

#### Scenario: 分钟条件与无时间戳记录

- **GIVEN** 文档一行时间戳分钟为 30，另一行无可识别时间戳
- **WHEN** 以分钟 30 过滤
- **THEN** 只有时间戳分钟为 30 的行命中

#### Scenario: 启用 tag 条件时无 tag 记录不命中

- **GIVEN** 文档含一行带 tag、一行不带 tag
- **WHEN** 以 tag 条件过滤且不开启排除
- **THEN** 不带 tag 的行不命中

### Requirement: tag 匹配方式与组合

tag 条件 SHALL 支持子串与整串两种匹配：子串匹配 MUST 判断 tag 文本是否包含给定值；整串匹配 MUST 判断 tag 文本是否与给定值相等；忽略大小写时，无论子串还是整串匹配，双方 MUST 先按 Unicode 小写化。「全部命中」与整串匹配组合时，单 tag 记录至多等于一个值，多个折叠后互不相同的值 MUST 视为无命中。排除模式下 MUST 保留未命中的记录。

#### Scenario: tag 子串匹配

- **GIVEN** 文档含 tag 为 `ActivityManager` 与 `WindowManager` 的行
- **WHEN** 以 tag `Manager`、子串匹配、任一命中过滤
- **THEN** 两行均命中

#### Scenario: tag 子串匹配全部命中

- **GIVEN** 文档含 tag 为 `ActivityManager` 的一行
- **WHEN** 以 tag `Activity` 与 `Manager`、子串匹配、全部命中过滤
- **THEN** 该行命中

#### Scenario: 子串匹配忽略大小写

- **GIVEN** 文档含 tag 为 `ActivityManager` 的一行
- **WHEN** 以 tag `manager`、子串匹配、忽略大小写过滤
- **THEN** 该行命中

#### Scenario: 整串匹配全部命中的多值

- **GIVEN** 文档含 tag 为 `Alpha` 的一行
- **WHEN** 以 tag `Alpha` 与 `Beta`、整串匹配、全部命中过滤
- **THEN** 该行不命中（单 tag 不能同时等于两个不同值）

#### Scenario: 整串匹配任一命中

- **GIVEN** 文档含 tag 为 `ActivityManager` 与 `WindowManager` 的行
- **WHEN** 以 tag `ActivityManager` 与 `WindowManager`、整串匹配、任一命中过滤
- **THEN** 两行均命中

#### Scenario: 整串匹配忽略大小写

- **GIVEN** 文档含 tag 为 `Alpha` 的一行
- **WHEN** 以 tag `alpha`、整串匹配、忽略大小写过滤
- **THEN** 该行命中

#### Scenario: 折叠后相同的多值在全部命中下成立

- **GIVEN** 文档含 tag 为 `Alpha` 的一行
- **WHEN** 以 tag `Alpha` 与 `alpha`、整串匹配、全部命中、忽略大小写过滤
- **THEN** 该行命中（两值折叠后相同）

#### Scenario: tag 排除

- **GIVEN** 文档含 tag 为 `ActivityManager` 与 `WindowManager` 的行
- **WHEN** 以 tag `ActivityManager`、开启排除过滤
- **THEN** `ActivityManager` 行被剔除，`WindowManager` 行保留

### Requirement: 正文匹配作用域

正文匹配 SHALL 只作用于记录正文：从日志头之后的消息起始位置到行尾，行尾为行终止符之前（`\n` 及紧邻其前的 `\r` 不计入）；行首时间戳、进程号、线程号、级别与 tag MUST NOT 参与正文匹配。消息起始位置以解析结果给出的消息偏移为准，该偏移之前为日志头；解析器未识别出消息起点的记录，整行视为正文。空正文 MUST 按长度为 0 的正文参与匹配：条件值为空词时命中，非空时不命中。正文取装载时的文件内容，与分页读取同源。

#### Scenario: 头部信息不参与匹配

- **GIVEN** 一行 tag 为 `ActivityManager`、正文不含该词
- **WHEN** 以 `ActivityManager` 作为正文条件过滤
- **THEN** 该行不命中

#### Scenario: 正文命中

- **GIVEN** 一行正文含 `started`
- **WHEN** 以 `started` 作为正文条件过滤
- **THEN** 该行命中

#### Scenario: 续行按自身正文参与匹配

- **GIVEN** 一行缩进续行正文含 `Foo.bar`，其上方记录的正文不含该词
- **WHEN** 以 `Foo.bar` 作为正文条件过滤
- **THEN** 命中的是续行自身，上方记录不命中

#### Scenario: 空正文与空词

- **GIVEN** 一行正文为空
- **WHEN** 以空词作为正文条件过滤
- **THEN** 该行命中

#### Scenario: 空正文与非空词

- **GIVEN** 一行正文为空
- **WHEN** 以 `started` 作为正文条件过滤
- **THEN** 该行不命中

### Requirement: 正文大小写等价

忽略大小写（默认）时，比较双方 SHALL 按 Unicode 小写化后逐字节相等即命中：ASCII 字母大小写 MUST 等价，`ß` 与 `ẞ` MUST 等价，带重音与不带重音 MUST NOT 等价，土耳其无点 `ı` 与 ASCII `i` MUST NOT 等价。区分大小写时 MUST 按原始字节精确比较。无法按 UTF-8 解码的正文 MUST 按替换字符参与小写化，MUST NOT 影响同一文档其余记录的判定。

#### Scenario: ASCII 大小写双向等价

- **GIVEN** 一行正文含 `Plain ASCII`
- **WHEN** 分别以 `plain`、`PLAIN`、`PlAiN` 过滤
- **THEN** 三次结果一致，该行均命中

#### Scenario: 区分大小写严格比较

- **GIVEN** 一行正文含 `PLAIN`
- **WHEN** 以 `plain` 过滤且开启区分大小写
- **THEN** 该行不命中

#### Scenario: 德语 eszett 等价

- **GIVEN** 一行正文含 `Straße`，另一行含 `ẞ`
- **WHEN** 以 `ß` 过滤且忽略大小写
- **THEN** 两行均命中

#### Scenario: 开尔文符号折叠为 ASCII k

- **GIVEN** 一行正文含 ASCII `k`
- **WHEN** 以开尔文符号（U+212A）过滤且忽略大小写
- **THEN** 该行命中

#### Scenario: 土耳其无点 i 不等价

- **GIVEN** 一行正文只含 `ı`，不含 ASCII 的 i 或 I
- **WHEN** 以 `i` 过滤且忽略大小写
- **THEN** 该行不命中

#### Scenario: 重音字符不等价

- **GIVEN** 一行正文含 `CAFÉ`，另一行含 `cafe`
- **WHEN** 以 `café` 过滤且忽略大小写
- **THEN** 只有含 `CAFÉ` 的行命中

#### Scenario: 非法 UTF-8 按替换字符参与比较

- **GIVEN** 一行正文含无法按 UTF-8 解码的字节，其余行正文正常
- **WHEN** 以含替换字符的正文条件、忽略大小写过滤
- **THEN** 含非法字节的行按替换字符命中，其余行的判定不受影响

### Requirement: 正文多值与排除

正文条件 SHALL 支持「全部命中」与「任一命中」，可由调用方选择，缺省为全部命中。空词在「任一命中」下 MUST 立即成立，在「全部命中」下 MUST 跳过、不构成否决。排除模式下 MUST 保留未命中的记录；条件值为非空词时，空正文视为未命中并在排除模式下保留；条件值为空词时，空正文按空词语义命中，排除模式下按命中剔除。

#### Scenario: 任一命中

- **GIVEN** 文档一行正文含 `start`，一行含 `timeout`
- **WHEN** 以 `start` 与 `timeout`、任一命中过滤
- **THEN** 两行均命中

#### Scenario: 全部命中

- **GIVEN** 一行正文同时含 `start` 与 `failed`
- **WHEN** 以 `start` 与 `failed`、全部命中过滤
- **THEN** 该行命中

#### Scenario: 空词在任一命中下立即成立

- **GIVEN** 条件含空词与一个不存在的词，组合方式为任一命中
- **WHEN** 执行过滤
- **THEN** 全部记录命中

#### Scenario: 空词在全部命中下不否决

- **GIVEN** 条件含空词与一个存在的词，组合方式为全部命中
- **WHEN** 执行过滤
- **THEN** 结果与只用该存在的词过滤相同

#### Scenario: 全部为空词的全部命中模式

- **GIVEN** 正文条件只含空词，组合方式为全部命中
- **WHEN** 执行过滤
- **THEN** 全部记录命中

#### Scenario: 空词在任一命中下与排除

- **GIVEN** 文档含正文非空的行，条件含空词与一个不存在的词，组合方式为任一命中，开启排除
- **WHEN** 执行过滤
- **THEN** 结果为空

#### Scenario: 全部为空词的全部命中与排除

- **GIVEN** 文档含任意记录，正文条件只含空词，组合方式为全部命中，开启排除
- **WHEN** 执行过滤
- **THEN** 结果为空

#### Scenario: 排除模式保留未命中记录

- **GIVEN** 文档一行正文含 `start`，一行不含，一行正文为空
- **WHEN** 以 `start`、开启排除过滤
- **THEN** 含 `start` 的行被剔除，其余两行保留

### Requirement: 结果集形态与顺序

有命中时结果集 SHALL 为严格升序、不重复的文档行号序列，且只含文档记录行（空行与横幅行从不入集）；无命中或空文档时为空结果集。结果集序号与文档行号分离，同一文档行号在结果集中至多出现一次。结果集内容 MUST NOT 因内部扫描方式不同而改变。

#### Scenario: 结果集升序不重复

- **GIVEN** 文档中第 3、7、8 行命中同一条件
- **WHEN** 执行过滤
- **THEN** 结果集依次为 3、7、8，不含重复项

#### Scenario: 空行与横幅不入结果集

- **GIVEN** 文档含空行、横幅行与若干记录行
- **WHEN** 执行过滤
- **THEN** 结果集只含记录行的文档行号

#### Scenario: 无命中返回空结果集

- **GIVEN** 文档中没有任何行命中条件
- **WHEN** 执行过滤
- **THEN** 结果集为空，不报错

#### Scenario: 块长不影响结论

- **GIVEN** 同一份文档与同一份条件，正文命中横跨块边界且候选稀疏
- **WHEN** 分别以默认块长与极小测试块长执行过滤
- **THEN** 两者结果集完全相同

### Requirement: 导航定位

结果集 MUST 支持按真实文档行号定位最近的结果行：该行在结果集中即返回对应位置；不在结果集中时取前后相邻结果行中距离更近者，距离相等取前一条；小于首条结果行取首条，大于末条结果行取末条；空结果集无定位。定位 MUST NOT 改变结果集。

#### Scenario: 命中定位

- **GIVEN** 结果集为文档行 3、7、8
- **WHEN** 按文档行 7 定位
- **THEN** 返回对应第 7 行的结果位置

#### Scenario: 平局取前一条

- **GIVEN** 结果集为文档行 0、2、5
- **WHEN** 按文档行 1 定位（到 0 与 2 距离相等）
- **THEN** 返回文档行 0 对应的结果位置

#### Scenario: 越界取首末

- **GIVEN** 结果集为文档行 2、5
- **WHEN** 分别按文档行 0 与文档行 9 定位
- **THEN** 前者返回首条，后者返回末条

#### Scenario: 空结果集无定位

- **GIVEN** 结果集为空
- **WHEN** 按任意文档行定位
- **THEN** 返回无定位，不报错

### Requirement: 与分页协作

过滤结果交给分页时，起点 SHALL 为真实文档行号而非结果集序号，并区分「锚点定位」与「顺序翻页」两种意图。锚点定位用于过滤条件变化后恢复视图：起点为宿主当前锚点，入口 MUST 定位结果集中最近的结果行——命中即自身；未命中取前后相邻结果行中距离更近者，距离相等取前一条；小于首条取首条，大于末条取末条；结果集为空时返回空页，不报错。顺序翻页用于连续加载：宿主传上一页末行的文档行号加一，入口 MUST 只向后定位第一条文档行号不小于起点的结果行，没有这样的结果行时 SHALL 返回空页，MUST NOT 向前回退。两种意图 MUST NOT 互相替代。过滤 MUST NOT 改变分页的条数上限、空页与错误口径。

#### Scenario: 按真实文档行起页

- **GIVEN** 结果集为文档行 2、5、9
- **WHEN** 以文档行 5 为起点请求一页
- **THEN** 页首为文档行 5 的命中行，不把 5 当结果集序号

#### Scenario: 顺序翻页不重复

- **GIVEN** 一页末行为文档行 5
- **WHEN** 以文档行 6 为起点请求下一页
- **THEN** 下一页从文档行 9 的命中行开始，不重复文档行 5

#### Scenario: 锚点被过滤掉取最近结果

- **GIVEN** 结果集为文档行 2、5、9，宿主当前锚点为文档行 7（不在结果集中）
- **WHEN** 以锚点定位请求一页
- **THEN** 页首为文档行 5 的命中行（到 5 与 9 距离相等，取前一条）

#### Scenario: 锚点超过末条结果取末条

- **GIVEN** 结果集为文档行 2、5、9，宿主当前锚点为文档行 10
- **WHEN** 以锚点定位请求一页
- **THEN** 页首为文档行 9 的命中行，不返回空页

#### Scenario: 空结果集锚点定位返回空页

- **GIVEN** 结果集为空
- **WHEN** 以任意文档行作为锚点请求一页
- **THEN** 返回空页，不报错

#### Scenario: 顺序翻页超过末条返回空页

- **GIVEN** 结果集为文档行 2、5、9，上一页末行为文档行 9
- **WHEN** 以文档行 10 为起点顺序翻页
- **THEN** 返回空页，不向前回退到文档行 9

### Requirement: 读取错误与装载内容一致

正文回读失败（源文件被截断、不可读或区间不足）时 MUST 返回读取错误并携带源路径与系统错误信息，MUST NOT 产出部分结果集，MUST NOT 改变源句柄状态。源文件在装载后被改名轮转、删除或替换时，过滤 MUST 继续以装载时的文件内容判定，不混入新内容。

#### Scenario: 源文件被截断

- **GIVEN** 文档装载完成后源文件被外部截断
- **WHEN** 执行需要回读正文的过滤
- **THEN** 返回读取错误并携带源路径与系统错误信息，不产出部分结果集，句柄状态不变

#### Scenario: 轮转后仍按装载内容判定

- **GIVEN** 文档装载完成后源文件被改名轮转
- **WHEN** 执行需要正文回读的过滤
- **THEN** 命中结论与装载时内容一致，不混入轮转后的新文件

#### Scenario: 替换后仍按装载内容判定

- **GIVEN** 文档装载完成后原路径被另一份文件替换
- **WHEN** 执行需要正文回读的过滤
- **THEN** 命中结论仍基于装载时的文件内容

#### Scenario: 删除后仍按装载内容判定

- **GIVEN** 文档装载完成后源文件被删除
- **WHEN** 执行需要回读正文的过滤
- **THEN** 命中结论与装载时内容一致

### Requirement: 过滤为只读操作

过滤 MUST NOT 修改索引快照、缓存、事件与进度，MUST NOT 使既有结果集或分页读取失效。同一份文档与同一份条件重复执行 MUST 得到相同结果集。

#### Scenario: 重复执行结果一致

- **GIVEN** 文件源装载完成
- **WHEN** 以同一条件连续执行两次过滤
- **THEN** 两次结果集完全相同

#### Scenario: 不改动既有读取

- **GIVEN** 文件源装载完成并已读取过一页
- **WHEN** 执行一次过滤
- **THEN** 既有分页读取的内容与行为不变
