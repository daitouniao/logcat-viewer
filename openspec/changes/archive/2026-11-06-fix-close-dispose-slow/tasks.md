- [x] 1.2 新增回归用例（`frmMainTests.cs`）：视图装入 20 万行并统计逐行构造回调次数 → 调用关闭前清理 → 销毁窗体 → 断言行数归零且销毁期间回调次数不再增长。用例名：`关闭前清理后视图行数归零且销毁不再逐行构造`。验证：该用例通过；若先于 1.1 编写须呈红（复现销毁逐行枚举），接线后转绿。**实测记录**：红态可确定性复现——临时注释清空行后该用例 FAIL（销毁期回调 200000 次 = 行数），恢复后为 0；用例必须 `_ = listView.Handle` 建句柄，否则无销毁流程、枚举不发生。
