# Spec Delta

## MODIFIED Requirements

### Requirement: 提交受理与装载完成

commit SHALL 在受理后立即返回，不等待暂存、解码与索引完成；返回值只表达受理结果，宿主 MUST NOT 将其当作装载完成。受理前的校验（句柄状态、请求参数、计划结果仍可用）SHALL 同步返回错误；受理后的运行期失败 MUST 经错误事件上报并把句柄置为失败态，MUST NOT 回填到已返回的调用。commit 受理本身不发布事件；文件源的完成以完成事件表示，采集源受理即进入采集运行状态，其终态仍是停止或错误。源描述 SHALL 经描述读取入口获取：受理后即可读取，渠道等静态字段即为终值（渠道在 plan 阶段确定、装载期间不变），本地直读源的身份与装载模式取 plan 阶段确定值：装载开始复核发现文件已变时身份更新为复核值、装载模式按未命中改为分块渐进，命中条目解码失败时装载模式改为分块渐进——两者均仅更新一次，代理暂存与采集源的身份为空，行数为当前已装载行数（初始为零）；装载完成后行数与文档大小取终值。宿主判定装载完成 MUST 以终态事件为准，进度只用于呈现。

#### Scenario: 提交在装载完成前返回

- **GIVEN** plan 已成功、目标是一份需要完整解析的大文件
- **WHEN** 宿主发起 commit
- **THEN** 调用在暂存与索引完成前返回受理结果，此时描述可读、行数为零，进度处于装载阶段

#### Scenario: 完成经事件告知

- **GIVEN** commit 已受理、装载仍在进行
- **WHEN** core 完成解析与索引
- **THEN** 发布完成事件，宿主据此判定装载完成；此后描述的行数与文档大小为终值

#### Scenario: 运行期失败只经事件

- **GIVEN** commit 已受理、随后直读打开失败
- **WHEN** 装载执行
- **THEN** commit 调用不携带该错误，错误事件携带错误码，句柄进入失败态并保留至显式释放

#### Scenario: 受理前错误同步返回

- **GIVEN** 句柄上的 commit 已受理
- **WHEN** 宿主再次发起 commit
- **THEN** 调用同步返回非法状态，不启动第二次装载

#### Scenario: 采集受理即运行

- **GIVEN** 采集请求的 commit 被受理
- **WHEN** 宿主读取描述与进度
- **THEN** 句柄进入采集运行状态、描述可读，不需要等待完成事件

### Requirement: 三轴源描述

commit 受理后 core SHALL 经描述读取入口提供源描述，其渠道、格式、编码三轴 MUST 互相正交，任一单轴变化不得牵动其余两轴。描述 SHALL 包含：显示路径与源路径分离、列声明（宿主只按列声明渲染，不自持列集）、四要素身份（大小、修改时间、首尾各 64 KB 指纹；本地直读源在 plan 阶段读样本算全、受理骨架即给出，装载开始时复核发现文件已变则更新为复核值；代理暂存源与采集源身份为空且属合法组合）、装载模式（一次到位或分块渐进；本地直读源命中缓存为一次到位，未命中为分块渐进，命中条目在装载开始解码失败时由一次到位更新为分块渐进且仅更新一次，暂存与采集源恒为分块渐进）、行数与文档大小、追加模式、租约性质与租约标识、时间语义。采集源没有用户路径，其显示路径 SHALL 为空值；宿主 MUST NOT 以显示路径作为采集源的标题或最近使用键，标题与最近使用口径归宿主。描述 SHALL 在 commit 受理时即产出骨架并随装载推进更新，失败态 SHALL 返回最后快照而非报错；宿主 MUST NOT 以描述可读推断源路径所指产物存在或装载成功。

#### Scenario: 三轴正交

- **GIVEN** 一个本地直读的 UTF-8 日志文件
- **WHEN** commit 受理后读取描述
- **THEN** 渠道、格式、编码三轴各自独立取值，改变其中一轴的输入不会连带改变其余两轴的取值逻辑

#### Scenario: 文件源身份受理即可读

- **GIVEN** 一个本地直读文件的 plan 已成功
- **WHEN** commit 受理后读取描述
- **THEN** 身份四要素已完整可读，取 plan 阶段算全的值，不因装载未完成而空缺

#### Scenario: 计划后文件被改写

- **GIVEN** plan 已成功、commit 受理前文件被外部改写
- **WHEN** 装载开始时复核身份
- **THEN** 身份更新为复核值，装载模式改为分块渐进，按未命中完整解析，描述与装载结果均对应文件当前内容

#### Scenario: 命中条目解码失败装载模式更新

- **GIVEN** plan 头部命中缓存、装载开始复核身份一致，但条目列数据损坏
- **WHEN** 装载开始解码条目失败并降级为完整解析
- **THEN** 描述中的装载模式更新为分块渐进且仅更新一次，身份保持复核值，不发布错误事件

#### Scenario: 显示路径不外泄暂存路径

- **GIVEN** 经代理暂存打开的文件
- **WHEN** 宿主消费源描述
- **THEN** 标题、最近使用与导出命名只使用用户原路径，暂存路径仅经源路径字段供内部使用

#### Scenario: 采集源身份为空属合法

- **GIVEN** 采集会话的 commit 已受理
- **WHEN** 宿主读取描述
- **THEN** 身份为空属合法组合，不构成失败

#### Scenario: 代理暂存源身份为空

- **GIVEN** 一次经代理暂存打开的文件源
- **WHEN** 宿主读取描述
- **THEN** 身份为空属合法组合，不构成失败；暂存文件身份不被补算

#### Scenario: 采集源无显示路径

- **GIVEN** 采集会话的 commit 已受理
- **WHEN** 宿主读取描述并构建标题
- **THEN** 显示路径为空值，宿主按渠道自行生成标题且不把它写入最近使用，不构成失败

#### Scenario: 失败态描述仍可读

- **GIVEN** 采集 commit 已受理，随即因临时目录不可写进入失败态，此前无任何一行可装载
- **WHEN** 宿主读取描述
- **THEN** 返回最后快照：列集、渠道与租约等静态字段齐全，行数为已落盘行数，源路径所指文件即使不存在也不构成错误

### Requirement: sidecar 缓存复用

core SHALL 以四要素身份为键，在宿主传入的缓存目录中查找索引缓存：命中判定 SHALL 在 plan 阶段完成，仅以条目的定长头部为判据（魔数、格式版本、行数、段长形状、总长与四要素身份），MUST NOT 依赖条目中字典与列数据的解码结果，MUST NOT 为此读取列数据；为此 plan 阶段须读取文件首尾样本算全身份（只读，不建目录、不写条目），并按头部校验结果登记在用条目。命中条目的列数据解码 SHALL 在装载开始时、身份复核通过后进行；命中且复核身份一致时，SHALL 复用索引、跳过文本解析（缓存不含文本，命中仍须打开源文件取文本）；未命中、身份不一致、头部校验失败、条目解码失败或版本不符时，SHALL 静默降级为完整解析，任何缓存异常 MUST NOT 使获取失败、MUST NOT 发布错误事件。缓存 SHALL 只服务本地直读源，暂存与采集产物 MUST NOT 入缓存。缓存字节格式 SHALL 与既有实现保持一致：旧缓存 MUST 可直接复用，新写条目 MUST 为同一格式。写入 SHALL 原子替换、不得留下半成品；写入失败 MUST NOT 影响装载结果。缓存容量 SHALL 受条目与目录两级上限约束，超限按最近使用回收，本进程的在用条目 MUST NOT 被回收。取消与关闭 MUST NOT 删除缓存条目。缓存目录与容量上限 SHALL 由宿主经配置快照传入，core MUST NOT 自行发明默认目录。

#### Scenario: 二次打开命中缓存

- **GIVEN** 同一本地文件此前已装载并写入缓存，且文件身份未变
- **WHEN** 宿主再次发起获取
- **THEN** 描述中的装载模式为一次到位；装载开始时解码条目并跳过解析，行数与文档大小与文件内容一致

#### Scenario: 身份变化降级解析

- **GIVEN** 缓存存在，但文件大小或修改时间已变
- **WHEN** 装载执行
- **THEN** 视为未命中并完整解析，装载结果与文件当前内容一致，缓存被更新

#### Scenario: 损坏条目静默降级

- **GIVEN** 缓存条目头部校验通过，但列数据被外部破坏
- **WHEN** 装载开始解码条目
- **THEN** 获取成功且结果为完整解析，不发布错误事件，损坏条目被替换，装载模式更新为分块渐进

#### Scenario: 版本不符视为未命中

- **GIVEN** 缓存条目携带的格式版本与当前实现不一致
- **WHEN** 装载执行
- **THEN** 按未命中处理并完整解析；低于当前版本的条目在原位置重写，高于当前版本的条目不被覆盖

#### Scenario: 只缓存本地直读源

- **GIVEN** 一次经代理暂存或采集的获取
- **WHEN** 装载完成
- **THEN** 不产生缓存条目，暂存与采集产物不入缓存

#### Scenario: 容量回收保留在用条目

- **GIVEN** 缓存目录超出容量上限，且其中条目正被本进程的活动源使用
- **WHEN** 回收执行
- **THEN** 按最近使用淘汰其他条目，在用条目与新写条目被保留

#### Scenario: 关闭不删缓存

- **GIVEN** 装载已命中或写入缓存条目
- **WHEN** 宿主关闭并释放该源
- **THEN** 缓存条目仍在，可被后续获取复用
