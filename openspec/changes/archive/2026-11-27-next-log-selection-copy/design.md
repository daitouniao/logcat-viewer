# Design

## Context

见 `proposal.md`。当前实现的关键现状：

- 日志行由自绘画布按视口绘制，画布本身不参与命中测试，鼠标事件落在其上的透明滚动容器；颜色只允许来自 `DesignTokens`（主题键两套必须对齐，已有测试守护）。
- 行数据按「起始行 + 条数」分页取回后解码为托管行模型，页缓存在页面供给层；任意时刻只有视口附近的页在内存里。
- 键盘事件已在主窗处理（目前只有 `Ctrl+End`），状态栏文案经本地化键生成。
- 当前没有过滤，行序 = 文档行序；未来过滤接入后行序将变为结果集序，选择与复制必须按同一序。

## Goals / Non-Goals

**Goals:**

- 选择集合与命中行都按「行序」表达，不依赖具体页是否已在缓存。
- Shift 区间选择在千万行文件上不产生与行数同阶的内存分配。
- 复制在后台取数，不阻塞滚动；复制内容与旧查看器「复制原始文本」一致。
- 选择状态不进入数据层，不改任何互操作导出。

**Non-Goals:**

- 不做框选、拖动选择、右键菜单、全选快捷键与「复制为表格行」。
- 不做跨文件/跨结果集的选择保持。
- 不为超大选择设置硬上限；复制规模的风险在「风险」节如实记录。

## Decisions

### D1 选择集合用区间集（有序不重叠区间），不用逐行集合

选择与手势的纯逻辑类型通过测试工程现有的 `InternalsVisibleTo` 暴露，不为了让测试可访问而把类型改成 public。

- 选择语义是「若干行区间」：Shift 选择天然是区间，Ctrl 单击是增删单行。
- 用逐行 `HashSet<long>` 时，Shift 选中 270 万行会产生同量级条目（数十 MB）；区间集只存边界，成员判定用二分查找，内存与区间数同阶（正常使用几十个）。
- 与「虚拟列表只渲染视口」同源：绘制时对每个可见行做成员判定，成本 O(log 区间数)。
- 备选：`HashSet<long>`（实现最简，但大区间不成立）；位图压缩（省内存但实现重、对增量切换不友好）——不取。

### D2 命中测试放在滚动容器，画布保持不可命中

- 画布当前不参与命中测试，滚动容器接收指针事件；点击位置换算为「行序 = (滚动偏移 + 局部 Y) / 行高」。
- 指针落点是滚动条/滑块时跳过，避免把拖动滚动条误判为选行；落在末行之后的留白或空文件区域时返回「无行」，不改动选择。
- 行的任意列位置（含最左侧 # 列）都命中同一行；# 列在本切片没有独立交互。
- 鼠标单击、触摸与触控板轻点统一走同一指针路径，不单独为鼠标左键分支。
- 命中换算使用画布现有的逻辑行高常量（与绘制同一常量），不做按字体的 DPI 实测校准。
- 成员判定只在每次绘制可见行时做区间二分，不预计算可见行位图（区间数通常为个位数）。
- 选择变化只触发画布重绘（重绘是既有的视口级绘制），不引入新的布局或控件树。

### D3 选择状态由主窗持有，页供给层不感知选择

- 主窗持有区间集与锚点行，画布通过依赖属性接收「选中判定」能力（或选中集快照），变化时重绘。
- 锚点不存在时按住 Shift 单击按普通单击处理：该行成为唯一选中行并成为锚点。
- 锚点只由普通单击与 Ctrl 单击更新；Shift 单击只按「锚点 ↔ 目标行」重算区间，连续 Shift 始终以最初锚点为准。
- 页供给层保持现状，只负责取页；选择与复制在界面层组合。
- 文件切换 / 重新装载时主窗清空选择；主题、语言、尺寸变化只重绘，不动选择（与既有「外观变化不改变查看位置」一致）。

### D4 复制按区间逐页取数，复用页缓存，后台拼装

- 复制需要范围内的原文；这些行可能不在当前页缓存里。
- 在页供给层增加「按行区间取行」的异步入口：命中缓存直接返回，缺页时按页大小顺序补齐（与视口取页同一条路径、同一份缓存），取完在后台拼装。
- 拼装内容 = 每个选中行的原始文本（已解码为托管字符串的原文），按行序用 `\n` 连接、末尾不加换行；这是旧查看器「复制原始文本」的口径。
- 复制期间不改选择，以触发时刻的选择快照为准；完成后以状态栏「已复制 N 行」反馈，N 为选中记录数（合并记录算 1 行）、按当前界面区域千分位格式，失败给失败提示，不弹模态框。
- 失败分两类并各用独立文案：取数失败（选区内有页命中失败集或本次取页失败）与剪贴板写入失败；两者都不写剪贴板。
- 选区内任一页取数失败（命中失败集或本次取页失败）时本次复制整体失败：不写剪贴板、状态栏提示失败，宁缺勿假，不产出缺行的复制结果；失败不自动重试，与页缓存的失败集口径一致。
- 选中记录本身是空行时按原文（空字符串）参与拼接并计入 N，不做跳过；复制完成后保留选择，不清空。
- 复制前不做行数二次确认；超大选区的一次性开销已在风险节记录。
- 备选：让数据层返回「按行号取原文」的导出接口——需要改 C ABI，超出本切片，且现有分页接口已足够。

### D5 选中行的视觉用新的语义色 token

- 选中行绘制底色，文字颜色不变；新增 token（如 `Surface.Selection`）并在明暗两套主题各给一值，沿用既有 token 完整性测试。
- 底色铺满整行可用宽度（含 Message 右侧空白），与旧查看器选中行观感一致。
- 不在控件内写颜色字面量；主题切换后画布按既有机制重绘，选中底色随主题变化。

### D6 快捷键与本地化

- `Ctrl+C` 在主窗键盘处理中识别；无选择时不消费按键、不改状态栏。
- 点击日志区后滚动容器获得键盘焦点，窗口级按键路由因此稳定落在主窗；打开文件完成后同样把焦点交回日志区。焦点在日志区时不额外绘制焦点边框（与旧查看器一致）。
- 详情窗口内的 `Ctrl+C` 由该窗口的只读文本框自行处理，主窗不拦截。
- 复制失败提示保持到下一次状态更新，不自动清除（与现有状态栏行为一致）。
- 复制成功/失败用既有稳定键本地化目录新增两条文案，中英各一份；缺键由既有测试报红。
- 复制过程不新增快捷键；`Ctrl+End` 等既有行为不变。

### D7 双击打开只读「完整记录」窗口

- 采用模态窗口（与旧查看器一致）；标题为「记录 #{源文件行号}」，行号取 # 列的数字，过滤接入后仍按源文件行号显示。
- 默认尺寸沿用旧查看器 1000×620，居中于主窗、不记忆用户调整，可自由拉伸且不设最小/最大尺寸；等宽字体回退链 `Consolas, Cascadia Mono, monospace`，不自动换行、双向滚动；Esc 与关闭按钮均可关闭，关闭后焦点回到日志列表。
- 只读 `TextBox` 自身提供选择与 `Ctrl+C`，不另设复制按钮；不迁移旧弹窗的「把字面的 \n 拆成真实换行」开关（本切片不做）。
- 窗口复用应用级主题资源，系统/应用主题变化后重绘；模态期间主窗菜单不可操作，因此语言切换在重开窗口后生效，不为详情窗口单独做实时语言切换。
- 双击用 Avalonia 内置 `DoubleTapped` 识别（跟随系统双击间隔），不手写计时；按两次单击处理：普通双击最终选择为被双击行单行；只有无修饰键双击打开窗口，Ctrl/Shift+双击只走选择手势、不打开窗口。
- 详情内容为完整的原始行（含时间、级别、pid/tid、tag 前缀），不是只取 message 正文；直接取当前页缓存中的可见行，不再发起取数；标题行号取该解码行的 # 数字（源文件行号），全流程不出现异步加载态。
- 标题固定用 `Record #{0}` / `记录 #{0}`，不做英文复数规则。
- 窗口设置 Owner 为主窗、不在任务栏单独占位；打开与关闭不更新状态栏文案。
- 单条记录过长时不为详情窗口设长度阈值或截断；超长文本的打开耗时记为已知风险。
- 备选：非模态单实例面板（需处理内容切换与焦点归属），实现面更大，本切片不取。

## Risks / Trade-offs

- [超大区间复制占用内存与时间] → 复制在后台取数与拼装，不阻塞滚动；第一版不设硬上限，已知一次性大选择可能产生很大字符串，后续需要时可加「复制中」进度或上限（不影响本规范）。
- [页缓存被选择/复制路径挤占] → 只读复用现有页缓存与失败集，不新增第二份缓存；失败页与视口一致地不重试。
- [未来过滤接入后行序含义变化] → 设计与规范统一用「行序」而非「文档行号」；过滤接入时只需把行序绑定到结果集序，选择逻辑不改。
- [滚动条拖动被误判为选行] → 指针事件源头判断，落在滚动条/滑块时不进入选择逻辑。
- [键盘焦点在输入控件时 Ctrl+C 被抢] → 当前窗口无输入框；后续加过滤框时只在非文本输入焦点下处理复制（设计已记录边界）。
- [无效 UTF-8 原文被 lossy 解码后复制] → 页解码本就是 lossy，复制口径与旧查看器「复制原始文本」一致（同样经 UTF-8 解码），接受，不做字节级还原。
- [详情窗口为模态，打开时不能操作主列表] → 与旧查看器行为一致；只读查看属短时操作，接受。
- [超长单行/超大记录打开详情] → 文本一次性赋值，极端超长记录可能有可感知停顿；不设阈值与截断，接受并记录，后续需要时再优化。
