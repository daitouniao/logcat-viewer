# Spec Delta

## MODIFIED Requirements

### Requirement: 查询开启与结果集

已装载并持有索引快照的文件源 SHALL 允许开启查询，携带过滤表达式；成功开启的查询 MUST 持有开启时刻的装载快照与结果集，其结果集语义与过滤能力一致：严格升序、不重复、只含记录行。未携带任何条件的查询 SHALL 得到包含全部记录行的结果集。同一文档 SHALL 允许同时存在多个查询，各自结果互不影响。过滤表达式不合过滤契约时 MUST 按该契约的错误口径拒绝且不产生查询：参数类问题返回参数错误并指明无效项，正文正则不合法返回正则无效并标明原因。源不处于已装载状态时 MUST 返回非法状态；源已关闭时 MUST 返回已关闭。开启查询 MUST NOT 改变源句柄状态、事件或进度。

#### Scenario: 按条件开启查询

- **GIVEN** 文件源装载完成，文档中有两行进程号为 100、一行进程号为 200
- **WHEN** 以进程号 100 开启查询
- **THEN** 查询建立成功，结果行数为 2

#### Scenario: 空条件包含全部记录行

- **GIVEN** 文件源装载完成，文档有 1000 行记录行
- **WHEN** 以空条件开启查询
- **THEN** 结果行数为 1000，顺序与文档一致

#### Scenario: 空文档查询为空

- **GIVEN** 文件源装载完成但文档没有记录行
- **WHEN** 以空条件开启查询
- **THEN** 查询建立成功、结果行数为 0；任意起点取页为空页，任意锚点定位返回无定位

#### Scenario: 非法条件不产生查询

- **GIVEN** 文件源装载完成
- **WHEN** 以非法过滤表达式开启查询
- **THEN** 返回参数错误并指明无效项，不产生查询

#### Scenario: 非法正则不产生查询

- **GIVEN** 文件源装载完成
- **WHEN** 以语法不合法的正文正则开启查询
- **THEN** 返回正则无效并标明原因，不产生查询，源句柄状态不变

#### Scenario: 未装载时拒绝

- **GIVEN** 文件源已受理但装载仍在进行
- **WHEN** 尝试开启查询
- **THEN** 返回非法状态，不产生查询

#### Scenario: 关闭后拒绝

- **GIVEN** 文件源句柄已关闭
- **WHEN** 尝试开启查询
- **THEN** 返回已关闭

#### Scenario: 多查询并存互不影响

- **GIVEN** 文件源装载完成
- **WHEN** 以两个不同条件分别开启查询
- **THEN** 两个查询各自返回符合自身条件的结果行数，互不影响
