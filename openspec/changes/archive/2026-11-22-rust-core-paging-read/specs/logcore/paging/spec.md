# Spec Delta

## Purpose

为宿主与 MCP 提供与索引同源的只读分页读取：按结果集序号取固定条数的行内容与展示所需字段，宿主不再自行映射或解析日志文件。

## ADDED Requirements

### Requirement: 分页读取入口

已装载文件源 SHALL 提供只读分页：宿主按结果集序号与条数请求一页，返回按序号升序排列的行。本能力下结果集为文档全部行，序号即文档行号。单页条数 MUST NOT 超过 core 声明的上限，超过 MUST 返回参数错误并指明字段；条数为负 MUST 返回参数错误并指明字段；条数为零 SHALL 返回空页；起始序号为负 MUST 返回参数错误；起始序号不小于当前行数时 SHALL 返回空页，不视为错误。页内各行 MUST 来自同一装载完成的索引快照，序号连续且不重复。同一句柄上的行数读取与页读取 MUST 由宿主串行调用，本能力不承诺二者并发安全；事件与进度仍按各自既有并发规则。

#### Scenario: 取页成功

- **GIVEN** 文件源装载完成、文档有 1000 行
- **WHEN** 宿主请求序号 100 起、20 条的一页
- **THEN** 返回 20 行，序号为 100 至 119，内容来自装载完成的索引快照

#### Scenario: 起始越界返回空页

- **GIVEN** 文件源装载完成、文档有 1000 行
- **WHEN** 宿主请求序号 1000 起的一页
- **THEN** 返回空页，不返回错误

#### Scenario: 超过单页上限被拒

- **GIVEN** 文件源装载完成
- **WHEN** 宿主请求的条数超过 core 声明的单页上限
- **THEN** 返回参数错误，参数指明超限的是条数字段，不返回部分页

#### Scenario: 负起始序号被拒

- **GIVEN** 文件源装载完成
- **WHEN** 宿主以负的起始序号请求一页
- **THEN** 返回参数错误，不返回任何行

#### Scenario: 负条数被拒

- **GIVEN** 文件源装载完成
- **WHEN** 宿主请求一页且条数为负
- **THEN** 返回参数错误并指明超限的是条数字段，不返回任何行

#### Scenario: 零条数返回空页

- **GIVEN** 文件源装载完成
- **WHEN** 宿主以条数零请求一页
- **THEN** 返回空页，不视为错误

### Requirement: 页缓冲所有权与释放

页读取成功时页数据 SHALL 由 core 分配为连续缓冲，宿主 MUST 在解析或拷贝完成后经释放入口交还；交还后宿主 MUST NOT 再读取或重复释放同一缓冲。释放入口 MUST 对空指针安全。页读取失败时 MUST NOT 产出需宿主释放的缓冲，宿主在错误分支 MUST NOT 读取或释放输出缓冲。

#### Scenario: 成功取页后交还缓冲

- **GIVEN** 文件源装载完成
- **WHEN** 宿主成功取页并解析完成
- **THEN** 宿主经释放入口交还缓冲，不产生泄漏或重复释放

#### Scenario: 取页失败无需释放

- **GIVEN** 文件源装载完成但源文件被外部截断
- **WHEN** 宿主请求覆盖被截断区域的一页
- **THEN** 返回读取错误，不产出需宿主释放的缓冲

### Requirement: 页内容与文本切片

页中每行 SHALL 携带结果集序号、原文、消息起始偏移、时间戳区间，以及列声明对应列的原始取值（级别码、进程号、线程号、tag）。时间戳区间 MUST 指向原文中可展示的时间文本，且只取决于行首时间戳形态，与进程号、线程号、级别、tag 是否识别无关；行首不含可识别时间戳时为空区间。消息正文由原文自消息起始偏移起算，偏移为零时取整行。tag 以可展示字符串下发，宿主 MUST NOT 依赖另行获取字典。空行与横幅行 MUST NOT 进入结果集。原文 MUST NOT 包含行尾换行（CRLF 或 LF）。宿主持有原文即可逐字节还原原始行正文；无法解码的字节由宿主按替换字符显示。

#### Scenario: threadtime 行切片

- **GIVEN** 文件源装载完成，其中一行为标准 threadtime 格式
- **WHEN** 宿主读取该行所在页
- **THEN** 时间戳区间为行首时间文本，消息起始偏移指向日志头之后，原文与源文件该行去除行尾换行后的字节一致

#### Scenario: 方括号 long 行切片

- **GIVEN** 文件源装载完成，其中一行为方括号 long 格式
- **WHEN** 宿主读取该行所在页
- **THEN** 时间戳区间从方括号前缀之后起算，消息正文取消息起始偏移之后的字节

#### Scenario: 无法识别时间戳的行

- **GIVEN** 结果集中一行不含可识别的时间戳
- **WHEN** 宿主读取该行所在页
- **THEN** 时间戳区间为空，消息正文按原始规则取正文，该行仍出现在结果集中

#### Scenario: 时间戳可识别但元数据未知

- **GIVEN** 结果集中一行行首是合法时间戳，其后没有可识别的进程号、线程号、级别与 tag
- **WHEN** 宿主读取该行所在页
- **THEN** 该行仍携带时间戳区间，进程号与线程号为未知哨兵，级别码为零，tag 为空字符串，宿主据此展示为空，消息正文为整行

### Requirement: 崩溃摘要字段

崩溃头行 SHALL 随页携带崩溃类别与摘要所需的异常类型、包名，使宿主无需另行查询即可渲染摘要；异常类型与包名可为空。非崩溃行 MUST NOT 携带崩溃摘要字段。

#### Scenario: Java 崩溃头随页返回

- **GIVEN** 文件源装载完成，结果集中包含一行 Java 崩溃头
- **WHEN** 宿主读取该行所在页
- **THEN** 该行携带崩溃类别、异常类型与包名，宿主可据此渲染摘要

#### Scenario: 异常类型缺失的崩溃头

- **GIVEN** 一行崩溃头没有可提取的异常类型
- **WHEN** 宿主读取该行所在页
- **THEN** 该行携带崩溃类别，异常类型为空，摘要降级显示原文而不报错

#### Scenario: 非崩溃行不带摘要字段

- **GIVEN** 结果集中的普通行
- **WHEN** 宿主读取该行所在页
- **THEN** 该行不携带崩溃摘要字段

### Requirement: 行数读取与页边界

宿主 SHALL 可独立读取当前可读行数；装载完成后该值 MUST 与源描述中的行数一致。页返回的行数 MUST 不超过请求条数，也不超过自起始序号起的剩余行数。本代支持的行数上限为 2,147,483,647，与 sidecar 行号、崩溃表行号的承载范围一致（页内序号用 32 位无符号，留有余量）；超出上限的源不在支持范围。

#### Scenario: 行数可读

- **GIVEN** 文件源装载完成
- **WHEN** 宿主读取行数
- **THEN** 返回与源描述一致的行数

#### Scenario: 末页短页

- **GIVEN** 文档有 1005 行
- **WHEN** 宿主请求序号 1000 起、20 条的一页
- **THEN** 返回 5 行，不补空行、不报越界

### Requirement: 源文件变化与页一致性

同一页内各行的原文 MUST 来自装载时对应的同一份文件内容。文件源装载后源路径被改名轮转、删除或替换时，页 SHALL 继续返回装载时索引对应的原文，不混入新路径文件的内容。源文件被原地截断重写不受一致保证；可检测的长度不足 MUST 返回读取错误，MUST NOT 返回部分页。

#### Scenario: 轮转、删除或替换后仍读装载内容

- **GIVEN** 文件源装载完成，源文件被改名轮转、删除，或同一路径被另一份文件替换
- **WHEN** 宿主请求覆盖原文件内容的页
- **THEN** 返回装载时索引对应的原文，不混入新路径文件的内容，不报错

#### Scenario: 轮转发生在两页之间

- **GIVEN** 第一页已返回后，源文件被改名轮转
- **WHEN** 宿主请求下一页
- **THEN** 两页的原文都来自装载时的文件内容，不混入轮转后的新文件

### Requirement: 读取状态与错误

页读取与行数读取 SHALL 仅在文件源装载完成且句柄未关闭时可用；其他状态 MUST 返回非法状态，关闭后 MUST 返回已关闭。源文件不可读、长度不足或区间越界时 MUST 返回读取错误并携带源路径与系统错误信息，MUST NOT 返回部分页，MUST NOT 改变句柄状态；装载后源文件变化时的页一致性见「源文件变化与页一致性」。页读取 MUST NOT 改变已有事件、进度与增量行为。

#### Scenario: 装载中读取被拒

- **GIVEN** 文件源 commit 已受理、装载仍在进行
- **WHEN** 宿主读取行数或请求一页
- **THEN** 返回非法状态，不返回部分索引内容，装载继续

#### Scenario: 关闭后读取

- **GIVEN** 文件源句柄已关闭
- **WHEN** 宿主读取行数或请求一页
- **THEN** 返回已关闭

#### Scenario: 源文件被截断

- **GIVEN** 文件源装载完成后源文件被外部截断
- **WHEN** 宿主请求覆盖被截断区域的一页
- **THEN** 返回读取错误并携带源路径与系统错误信息，不返回错位文本，句柄状态不变

#### Scenario: 读取失败不产生部分页

- **GIVEN** 一页中的部分行可读、部分行读取失败
- **WHEN** 宿主请求该页
- **THEN** 整页返回读取错误，不返回部分行
