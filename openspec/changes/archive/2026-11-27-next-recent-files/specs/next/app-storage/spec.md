# Spec Delta

## MODIFIED Requirements

### Requirement: 设置项互不覆盖

任一次保存 MUST NOT 清除本次未修改的其他设置项。语言、主题与最近文件分别修改后，三项 SHALL 同时保留。

#### Scenario: 交替修改语言与主题

- **WHEN** 用户先切换主题、再切换语言，随后重启应用
- **THEN** 重启后语言与主题均为最后选择的值

#### Scenario: 打开文件后切换主题

- **WHEN** 用户成功打开一个日志文件后切换主题并重启应用
- **THEN** 最近文件列表包含该文件，主题为最后选择的主题，语言保持原值

### Requirement: 本轮设置键面

本轮应用 SHALL 只持久化界面语言、主题与最近文件三项。设置文件中出现未被识别的键时，应用 MUST 正常启动且行为不受影响；保存时 MUST 只写已识别的键，MUST NOT 把未知键回写。

#### Scenario: 文件含未知键

- **WHEN** 设置文件中含当前实现不认识的键
- **THEN** 应用正常启动，语言、主题与最近文件按已知键生效

#### Scenario: 保存丢弃未知键

- **GIVEN** 设置文件含一个当前实现不认识的键
- **WHEN** 用户修改语言或主题触发保存
- **THEN** 保存后的文件只含已识别的键，未知键不再存在，应用行为不受影响
