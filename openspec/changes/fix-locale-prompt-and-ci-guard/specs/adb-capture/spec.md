# Spec Delta

## ADDED Requirements

### Requirement: 清除入口的文案本地化

「清空日志」按钮文本与清除结果反馈（成功 / 失败）的界面文案 SHALL 随界面语言变化，
SHALL NOT 在英文界面显示中文文案。

#### Scenario: 英文界面下清除入口已译

- **WHEN** 界面语言为英文
- **THEN** 「清空日志」按钮文本为英文

#### Scenario: 英文界面下清除反馈已译

- **WHEN** 界面语言为英文，用户触发缓冲区清除且清除成功
- **THEN** 状态栏的成功反馈为英文

#### Scenario: 英文界面下清除失败反馈已译

- **WHEN** 界面语言为英文，用户触发缓冲区清除且清除失败
- **THEN** 状态栏的失败反馈为英文，且包含失败原因
