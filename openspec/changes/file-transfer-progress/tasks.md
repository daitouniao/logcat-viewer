# Tasks

实施依据：specs/device-file-transfer/spec.md（行为契约）、design.md（决策 D1–D10）。测试口径：仓库内 tstrun 反射 runner，基线数字以 `docs/TESTING.md` 为准；每组自带该组应落的用例，不堆到最后。

## 1. 进度映射内核（纯函数，可测）

- [ ] 1.1 抽出「字节数 → 百分比」纯函数：入参为已传字节与总字节，输出百分比；总字节不可信（0 或未知）时返回「不可用」判定而非 0；百分比钳制在 0–100；进度回退时取历史较大值防倒退（design D1/D2）
- [ ] 1.2 抽出「多文件总字节」聚合：上传侧取本机文件长度、下载侧取目录列表中的文件大小；任一项不可知时整体分母判为不可用
- [ ] 1.3 新增单测：总字节为 0、进度回退、越界 100%、多文件按字节折算（1 个大文件 + 9 个小文件，整体百分比按字节而非按个数）——验证：tstrun 该组用例全过（用例须为同步方法，`async Task` 会被 tstrun 静默跳过）

## 2. 传输链路接入字节进度（design D1/D4/D5）

- [ ] 2.1 设备管理层 Push/Pull 增加可选进度回调形参：把同步通道自带的字节回调映射成项目惯用的进度形状，不把库的回调类型外泄到上层（design D1/D5）
- [ ] 2.2 设备文件面板的上传/下载方法透传进度，并按「是否落在字节通道内」划分阶段：准备（查属主、建目录）→ 字节（推/拉中转文件）→ 收尾（设备端拷贝、放开读权限、改属主、删中转文件）；直连路径不产生阶段（design D4）
- [ ] 2.3 上传后的刷盘步骤归入非字节阶段上报（它不产生字节回调，落在字节阶段会让条静止）
- [ ] 2.4 新增单测：阶段序列形状（准备 → 字节 → 收尾，字节阶段只出现在中转路径）与直连路径无阶段——验证：tstrun 该组用例全过

## 3. 进度条呈现与文案国际化（design D2/D3/D5/D10）

- [ ] 3.1 文件浏览对话框的传输编排：进度条改 0–100 百分比，按本次传输总字节折算；总量在传输开始前算清；文件计数降级为状态文案的一部分
- [ ] 3.2 不确定态：非字节阶段把进度条切为持续滚动的样式，进入字节阶段切回显示百分比，离开再切回；样式切换不得导致布局跳动
- [ ] 3.3 终态：传输结束（含部分失败）时先把进度条置满再隐藏；异常终止时进度条不得停留在中间态
- [ ] 3.4 传输中文案改走资源键：序号/总数 + 文件名、阶段动作说明、结果统计三处；新增键统一放进文件面板所属的文案表分片（键=中文原文，禁硬编码插值、禁前缀拼接）（design D10）
- [ ] 3.5 跑既有文案守卫测试（缺译文扫描）确认新增键齐备、且未与其他表重复定义——验证：tstrun 过滤集全过

## 4. 互斥、刷新覆盖与落点告知（design D7/D8/D9）

- [ ] 4.1 占用闸门扩展到本机内复制：设备传输与本机复制在同一窗口内互斥，第二次触发被拒绝并提示「正在传输，请稍候」
- [ ] 4.2 进度条生命周期收口：闸门退出时统一收起进度条并恢复按钮，异常路径同样收起（现状本机复制无保护，条会残留）
- [ ] 4.3 刷新覆盖三条路径：传输成功、传输异常、展开后无可传输文件，均刷新目标栏当前目录（上传刷设备栏、下载刷本机栏）
- [ ] 4.4 落点告知：传输目标不是目标栏当前目录（拖放到子目录项）时，状态栏说明文件落在哪个子目录
- [ ] 4.5 新增单测：互斥拒绝路径、空集路径触发刷新——验证：tstrun 该组用例全过
