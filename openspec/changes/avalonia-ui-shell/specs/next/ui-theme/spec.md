# Spec Delta

## Purpose

定义新界面宿主的明暗主题与配色契约：主题选择如何生效、哪些可见区域必须随之变化、日志领域色在两种主题下是否可读，确保用户不必因主题切换而重启或重载文件。

## ADDED Requirements

### Requirement: 主题三态与即时生效

界面 SHALL 提供浅色、深色、跟随系统三种主题选择；用户切换后，全部可见界面 SHALL 立即以目标主题呈现，无需重启应用或重新打开文件。

#### Scenario: 从浅色切到深色

- **WHEN** 界面当前为浅色主题，用户选择深色
- **THEN** 当前窗口及其全部子区域立即以深色配色呈现，已打开的文件保持打开

#### Scenario: 选择跟随系统时系统主题变化

- **WHEN** 用户选择跟随系统，随后操作系统切换为深色
- **THEN** 界面自动以深色呈现，无需用户再次操作

#### Scenario: 主题选择在重启后保持

- **WHEN** 用户选择深色后关闭并重新启动应用
- **THEN** 应用以深色主题启动

### Requirement: 可见区域无配色残留

在任一主题下，全部可见区域 SHALL 使用当前主题的配色，包括列表区域、列标题、滚动条、输入框、菜单与弹窗；界面 MUST NOT 出现与当前主题不一致的浅色或深色块。

#### Scenario: 深色主题下的列表与输入区域

- **WHEN** 界面处于深色主题，列表展示日志且过滤输入框可见
- **THEN** 列表、列标题、滚动条与输入框均为深色配色，不出现白色或浅灰残留区域

#### Scenario: 深色主题下打开对话框

- **WHEN** 界面处于深色主题，用户打开应用内的弹窗
- **THEN** 弹窗以深色配色呈现

### Requirement: 切换主题不丢失界面状态

主题切换 SHALL 只改变外观；当前打开的文件、滚动位置、当前可见行与标记状态 MUST 保持不变。

#### Scenario: 滚动后切换主题

- **WHEN** 用户滚动到某位置后切换主题
- **THEN** 可见的首行与切换前相同，界面不回到文件顶部、不重新加载文件

### Requirement: 日志领域色在两套主题下可读

日志级别标识、标记行底色与输入提示色 SHALL 在浅色与深色主题下分别定义，且在各自背景下可清晰区分；同一语义在两种主题下 MUST 表达相同含义。

#### Scenario: 深色主题下的级别区分

- **WHEN** 界面处于深色主题，列表同时展示多个不同级别的日志行
- **THEN** 各级别之间可凭颜色与文字内容清晰区分，不出现与背景混同而无法辨认的级别

#### Scenario: 两种主题下标记行均可辨识

- **WHEN** 用户标记若干日志行，并分别以浅色与深色主题查看
- **THEN** 标记行在两种主题下均能与未标记行区分
