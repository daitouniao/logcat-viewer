# 项目经验（memory）

> 创建：2026-10-24　|　最后更新：2026-10-24
> 本目录沉淀**跨 change 可复用的实战经验**：踩过的坑、定下来的纪律、每次大型操作后
> 值得记住的硬规律。收录标准只有一条——**能改变下一次操作的规则**才写进来。

## 与其它文档的分工

| 位置                   | 管什么                                                         |
| ---------------------- | -------------------------------------------------------------- |
| `docs/TESTING.md`      | 怎么跑测试、覆盖率怎么出（操作入口）                           |
| `docs/UT-AUDIT.md`     | 测试是否真的有效（变异测试审计结论与变异点清单）               |
| `docs/BUILDING.md`     | 怎么构建与发布                                                 |
| `docs/archive/`        | 已完结的设计 / 缺陷报告存档（不再维护）                        |
| `docs/memory/`（本目录） | **经验与纪律**——为什么是这么做、什么做法被证明会出事          |

## 收录原则

1. **只收能改变下次行为的规则**：操作步骤归 TESTING / BUILDING，审计结论归 UT-AUDIT，
   本目录只收「不复述就会重复踩坑」的硬规律。
2. **自包含**：不引用未入库文档，规则本身要写清；链接只指向库内文档。
3. **带日期与出处**：注明发现日期与背景 change，便于判断是否仍然成立。
4. **不存密钥、凭据、临时路径**；过程性排查记录不在此列。
